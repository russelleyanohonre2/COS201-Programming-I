## Requirements

Install a Java Development Kit (JDK) and ensure `java` and `javac` are available in your terminal.

## Compile and Run

Run each command from the directory containing that `.java` file. For example:

```bash
cd week01
javac FirstProgram.java
java FirstProgram
```

For Week 2:

```bash
cd week02
javac HelloWorld.java
java HelloWorld
javac StudentProfile.java
java StudentProfile
```

For Week 3, compile and run each program separately:

```bash
cd week03
javac SimpleCalculator.java
java SimpleCalculator
javac AverageCalculator.java
java AverageCalculator
javac ItemCost.java
java ItemCost
```

## Testing

Try several inputs for each program and compare the output with the expected calculations. `SimpleCalculator` handles a zero second number without attempting division by zero.
